# VYNIX Beta
Native Android music player starter, version 1.2.6-beta.

## Current scope
- Kotlin + Jetpack Compose foundation
- Dark graphite UI with lavender accent
- Five-tab navigation
- Local audio picker, library, and title search
- Mini-player UI
- GitHub Actions debug APK artifact

## Build
Open Actions → VYNIX Android Beta → Run workflow. Download the artifact named VYNIX-Beta-APK.

## Status
This is a starter beta, not a complete streaming aggregator. Actual playback service/session, persistent queue, and streaming-provider integrations require further implementation and testing. Provider integrations will use supported APIs and comply with each service's terms.
